# Ideamagix Review Test Assignment

## Project
Responsive Total Knee Replacement webpage recreated from the supplied reference design.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- jQuery
- Owl Carousel

## Requirements Implemented
1. HTML5 semantic structure.
2. Responsive webpage for desktop, tablet and mobile.
3. Lazy loading on content images using `loading="lazy"`.
4. Owl Carousel for Patient Stories, Doctors and Hospitals.
5. Modern-browser compatible HTML/CSS/JavaScript.
6. Dummy images and dummy content where required.
7. Pure JavaScript mobile navigation menu.
8. Full-screen page loader that fades after page load.
9. Sticky enquiry form on desktop; it becomes normal-flow on smaller screens.

## Project Structure
- `index.html` - main webpage
- `css/style.css` - complete responsive styling
- `js/script.js` - loader, mobile menu, form handling and Owl Carousel
- `assets/` - local dummy SVG images
- `database.sql` - database dump included for submission requirements
